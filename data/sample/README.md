# data/sample

Small, **documented, real** sample datasets used for development and tests.

Rules:
- Never fabricate or randomly generate data and present it as real poultry data.
- Every dataset needs a matching entry in `docs/research/datasets.md` with source, URL, license, collection date, column dictionary and known limitations.
- Large files go in `data/raw/` (git ignores them). They are then uploaded through the app, processed into `data/processed/` and stored in HDFS.

No datasets have been added yet.
